## نمایاں پروجیکٹس

- [FITTER-AI](https://github.com/sailxx/FITTER-AI) Telegram بوٹ ہے جو آپ کے کھانے کی تصویر سے کیلوریز کا تخمینہ لگاتا ہے۔
- [Okto](https://github.com/sailxx/Okto) Android , Windows اور ویب کے لیے ایک منصوبہ ساز ہے، جس میں کام، ایک کیلنڈر، اور ایک فوکس ٹائمر ہے۔

- [TrayMixer](https://github.com/sailxx/TrayMixer) Windows 11 اور Linux (پیش نظارہ) پر سسٹم ٹرے سے فی ایپ والیوم کو کنٹرول کرتا ہے۔

## میرے بارے میں

میں ولاد ہوں، ایک نوجوان، پرجوش ڈویلپر جو ٹیکنالوجی اور پروگرامنگ سے محبت کرتا ہے۔ میں ہمیشہ سیکھتا ہوں، اپنی صلاحیتوں کو تیز کرتا ہوں، اور جو کچھ میں سیکھتا ہوں اسے عملی جامہ پہناتا ہوں۔ آپ مجھے زیادہ تر دنوں GitHub پر، میرے ذخیروں پر کام کرتے ہوئے، شپنگ اپ ڈیٹس، اور نئے آئیڈیاز کے ساتھ تجربہ کرتے ہوئے پائیں گے۔

میں Windows 11 اور Fedora Linux VS کوڈ اور Android اسٹوڈیو کے ساتھ استعمال کرتا ہوں۔ میں JavaScript, TypeScript, Kotlin, C#, HTML, CSS, JSON اور SVG کے ساتھ کام کرتا ہوں۔ میں روسی، انگریزی اور اطالوی بولتا ہوں، اور میں UI ڈیزائن، گیمز اور بلڈنگ پی سی سے لطف اندوز ہوتا ہوں۔
