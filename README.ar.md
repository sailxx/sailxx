## مشاريع مميزة

- [FITTER-AI](https://github.com/sailxx/FITTER-AI) هو روبوت Telegram يقوم بتقدير السعرات الحرارية من صورة وجبتك.
- [Okto](https://github.com/sailxx/Okto) هو مخطط لـ Android و Windows والويب، مع المهام والتقويم ومؤقت التركيز.
- [Tobi](https://github.com/sailxx/Tobi) تراقب Claude Code و Codex و Cursor على Windows 11 وتتيح لك الموافقة على الإجراءات بنقرة واحدة.
- [TrayMixer](https://github.com/sailxx/TrayMixer) يتحكم في مستوى الصوت لكل تطبيق من علبة النظام على Windows 11 وLinux (معاينة).

## ْعَنِّي

أنا فلاد، مطور شاب وطموح يحب التكنولوجيا والبرمجة. أنا أتعلم دائمًا، وأصقل مهاراتي، وأضع ما أتعلمه موضع التنفيذ. ستجدني على GitHub في معظم الأيام، حيث أعمل على مستودعاتي، وأشحن التحديثات، وأجرب أفكارًا جديدة.

أستخدم Windows 11 وFedora Linux مع VS Code وAndroid Studio. أعمل مع JavaScript وTypeScript وKotlin وC# وHTML وCSS وJSON وSVG. أنا أتحدث الروسية والإنجليزية والإيطالية، وأستمتع بتصميم UI والألعاب وبناء أجهزة الكمبيوتر.
