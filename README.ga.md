## Tionscadail faoi thrácht

- [FITTER-AI](https://github.com/sailxx/FITTER-AI) is bot Telegram a dhéanann calories ó ghrianghraf de do bhéile a mheas.
- [Okto](https://github.com/sailxx/Okto) Is pleanálaí é le haghaidh Android , Windows , agus an gréasán, le tascanna, féilire agus lasc ama fócais.
- [Tobi](https://github.com/sailxx/Tobi) monatóireacht ar Claude Code , Codex , agus Cúrsóir ar Windows 11 agus ligeann duit gníomhartha a cheadú i gceann cliceáil.
- [TrayMixer](https://github.com/sailxx/TrayMixer) rialuithe toirte in aghaidh an app ó thráidire an chórais ar Windows 11 agus Linux (réamhamharc).

## Maidir liomsa

Is mise Vlad, forbróir óg, uaillmhianach a bhfuil grá aige do theicneolaíocht agus do ríomhchlárú. Bím i gcónaí ag foghlaim, ag géarú mo scileanna, agus ag cur an méid a fhoghlaimím i bhfeidhm. Gheobhaidh tú mé ar GitHub an chuid is mó de na laethanta, ag obair ar mo stórtha, ag seoladh nuashonruithe, agus ag triail smaointe nua.

Úsáidim Windows 11 agus Fedora Linux le Cód VS agus Android Studio. Oibrím le JavaScript, TypeScript, Kotlin, C#, HTML , CSS , JSON , agus SVG . Labhraím Rúisis, Béarla agus Iodáilis, agus bainim taitneamh as dearadh UI, cluichí agus ríomhairí a thógáil.
