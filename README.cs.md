## Doporučené projekty

- [FITTER-AI](https://github.com/sailxx/FITTER-AI) je robot Telegram, který odhaduje kalorie z fotografie vašeho jídla.
- [Okto](https://github.com/sailxx/Okto) je plánovač pro Android , Windows a web s úkoly, kalendářem a časovačem zaostření.
- [Tobi](https://github.com/sailxx/Tobi) monitoruje Claude Code , Codex a kurzor na Windows 11 a umožňuje vám schvalovat akce jedním kliknutím.
- [TrayMixer](https://github.com/sailxx/TrayMixer) ovládá hlasitost jednotlivých aplikací ze systémové lišty na Windows 11 a Linux (náhled).

## O mně

Jsem Vlad, mladý, ambiciózní vývojář, který miluje technologie a programování. Stále se učím, zdokonaluji své dovednosti a to, co jsem se naučil, uvádím do praxe. Většinu dní mě najdete na GitHub, kde pracuji na svých úložištích, posílám aktualizace a experimentuji s novými nápady.

Používám Windows 11 a Fedoru Linux s VS Code a Android Studio. Pracuji s JavaScript, TypeScript, Kotlin, C#, HTML, CSS, JSON a SVG. Mluvím rusky, anglicky a italsky a baví mě design UI, hry a sestavování PC.
