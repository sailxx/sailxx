## Proiecte prezentate

- [FITTER-AI](https://github.com/sailxx/FITTER-AI) este un bot Telegram care estimează caloriile dintr-o fotografie a mesei tale.
- [Okto](https://github.com/sailxx/Okto) este un planificator pentru Android , Windows și web, cu sarcini, un calendar și un temporizator de focalizare.
- [Tobi](https://github.com/sailxx/Tobi) monitorizează Claude Code , Codex și Cursor pe Windows 11 și vă permite să aprobați acțiuni cu un singur clic.
- [TrayMixer](https://github.com/sailxx/TrayMixer) controlează volumul per aplicație din bara de sistem pe Windows 11 și Linux (previzualizare).
