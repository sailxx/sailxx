## Progetti in primo piano

- [FITTER-AI](https://github.com/sailxx/FITTER-AI) è un bot Telegram che stima le calorie da una foto del tuo pasto.
- [Okto](https://github.com/sailxx/Okto) è un pianificatore per Android, Windows e il Web, con attività, un calendario e un timer di messa a fuoco.
- [Tobi](https://github.com/sailxx/Tobi) monitora Claude Code, Codex e Cursor su Windows 11 e ti consente di approvare le azioni con un clic.
- [TrayMixer](https://github.com/sailxx/TrayMixer) controlla il volume per app dalla barra delle applicazioni su Windows 11 e Linux (anteprima).
