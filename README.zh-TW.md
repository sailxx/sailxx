## 特色項目

- [FITTER-AI](https://github.com/sailxx/FITTER-AI) 是一個 Telegram 機器人，可以根據您的餐點照片估算卡路里。
- [Okto](https://github.com/sailxx/Okto) 是 Android 、 Windows 和網路的計劃程序，帶有任務、日曆和焦點計時器。
- [Tobi](https://github.com/sailxx/Tobi) 監控 Claude Code 、 Codex 和 Windows 11 上的遊標，並讓您一鍵批准操作。
- [TrayMixer](https://github.com/sailxx/TrayMixer) 從 Windows 11 和 Linux（預覽版）上的系統托盤控制每個應用程式的音量。
