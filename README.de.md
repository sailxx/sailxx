## Ausgewählte Projekte

- [FITTER-AI](https://github.com/sailxx/FITTER-AI) ist ein Telegram-Bot, der die Kalorien anhand eines Fotos Ihrer Mahlzeit schätzt.
- [Okto](https://github.com/sailxx/Okto) ist ein Planer für Android, Windows und das Web mit Aufgaben, einem Kalender und einem Fokus-Timer.
- [Tobi](https://github.com/sailxx/Tobi) überwacht Claude Code, Codex und Cursor auf Windows 11 und ermöglicht Ihnen die Genehmigung von Aktionen mit einem Klick.
- [TrayMixer](https://github.com/sailxx/TrayMixer) Steuert die Lautstärke pro App über die Taskleiste auf Windows 11 und Linux (Vorschau).
