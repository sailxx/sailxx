## Projets en vedette

- [FITTER-AI](https://github.com/sailxx/FITTER-AI) est un robot Telegram qui estime les calories à partir d'une photo de votre repas.
- [Okto](https://github.com/sailxx/Okto) est un planificateur pour Android , Windows et le Web, avec des tâches, un calendrier et un minuteur de mise au point.
- [Tobi](https://github.com/sailxx/Tobi) surveille Claude Code, Codex et Cursor sur Windows 11 et vous permet d'approuver les actions en un seul clic.
- [TrayMixer](https://github.com/sailxx/TrayMixer) contrôle le volume par application à partir de la barre d'état système sur Windows 11 et Linux (aperçu).
