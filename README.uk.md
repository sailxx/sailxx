## Рекомендовані проекти

- [FITTER-AI](https://github.com/sailxx/FITTER-AI) це бот Telegram, який оцінює калорії за фотографією вашої страви.
- [Okto](https://github.com/sailxx/Okto) це планувальник для Android , Windows та Інтернету із завданнями, календарем і таймером фокусування.
- [Tobi](https://github.com/sailxx/Tobi) відстежує Claude Code , Codex і курсор на Windows 11 і дозволяє підтверджувати дії одним клацанням миші.
- [TrayMixer](https://github.com/sailxx/TrayMixer) контролює гучність кожної програми з панелі завдань на Windows 11 і Linux (попередній перегляд).

## про мене

Я Влад, молодий амбітний розробник, який любить технології та програмування. Я завжди вчуся, вдосконалюю свої навички та застосовую те, що навчився, на практиці. Ви знайдете мене на GitHub більшість днів, я працюю над моїми репозиторіями, доставляю оновлення та експериментую з новими ідеями.

Я використовую Windows 11 і Fedora Linux із VS Code і Android Studio. Я працюю з JavaScript, TypeScript, Kotlin, C#, HTML, CSS, JSON і SVG. Я розмовляю російською, англійською та італійською мовами, мені подобається дизайн UI, ігри та створення ПК.
