## 주요 프로젝트

- [FITTER-AI](https://github.com/sailxx/FITTER-AI) 식사 사진에서 칼로리를 추정하는 Telegram 봇입니다.
- [Okto](https://github.com/sailxx/Okto) 작업, 달력 및 포커스 타이머가 포함된 Android, Windows 및 웹용 플래너입니다.
- [Tobi](https://github.com/sailxx/Tobi) Claude Code , Codex , Windows 11의 커서를 모니터링하고 한 번의 클릭으로 작업을 승인할 수 있습니다.
- [TrayMixer](https://github.com/sailxx/TrayMixer) Windows 11 및 Linux(미리보기)의 시스템 트레이에서 앱별 볼륨을 제어합니다.

## 나에 대해

저는 기술과 프로그래밍을 사랑하는 젊고 야심찬 개발자 Vlad입니다. 나는 항상 배우고, 기술을 연마하고, 배운 것을 실천에 옮기고 있습니다. 대부분의 날 GitHub에서 저를 만나실 수 있으며, 리포지토리 작업을 하고, 업데이트를 제공하고, 새로운 아이디어를 실험하고 있습니다.

저는 VS 코드 및 Android Studio와 함께 Windows 11 및 Fedora Linux를 사용합니다. 저는 JavaScript, TypeScript, Kotlin, C#, HTML , CSS , JSON 및 SVG 를 사용하여 작업합니다. 저는 러시아어, 영어, 이탈리아어를 구사하며 UI 디자인, 게임, PC 구축을 즐깁니다.
