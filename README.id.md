## Proyek unggulan

- [FITTER-AI](https://github.com/sailxx/FITTER-AI) adalah bot Telegram yang memperkirakan kalori dari foto makanan Anda.
- [Okto](https://github.com/sailxx/Okto) adalah perencana untuk Android , Windows , dan web, dengan tugas, kalender, dan pengatur waktu fokus.
- [Tobi](https://github.com/sailxx/Tobi) memantau Claude Code, Codex, dan Kursor di Windows 11 dan memungkinkan Anda menyetujui tindakan dalam satu klik.
- [TrayMixer](https://github.com/sailxx/TrayMixer) mengontrol volume per aplikasi dari baki sistem pada Windows 11 dan Linux (pratinjau).
