## Wyróżnione projekty

- [FITTER-AI](https://github.com/sailxx/FITTER-AI) to bot Telegram, który oblicza kalorie na podstawie zdjęcia Twojego posiłku.
- [Okto](https://github.com/sailxx/Okto) to planista dla Android, Windows i Internetu, z zadaniami, kalendarzem i licznikiem czasu.
- [Tobi](https://github.com/sailxx/Tobi) monitoruje Claude Code, Codex i Cursor na Windows 11 i pozwala zatwierdzać działania jednym kliknięciem.
- [TrayMixer](https://github.com/sailxx/TrayMixer) kontroluje głośność poszczególnych aplikacji z paska zadań w modelach Windows 11 i Linux (wersja zapoznawcza).

## O mnie

Jestem Vlad, młody, ambitny programista, który kocha technologię i programowanie. Cały czas się uczę, doskonalę swoje umiejętności i wdrażam zdobytą wiedzę w praktykę. Przez większość dni znajdziesz mnie na GitHub, gdzie pracuję nad moimi repozytoriami, wysyłam aktualizacje i eksperymentuję z nowymi pomysłami.

Używam Windows 11 i Fedory Linux z kodem VS i Android Studio. Pracuję z JavaScript, TypeScript, Kotlin, C#, HTML, CSS, JSON i SVG. Mówię po rosyjsku, angielsku i włosku i lubię projektować, grać i budować komputery UI.
