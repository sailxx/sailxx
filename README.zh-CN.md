## 特色项目

- [FITTER-AI](https://github.com/sailxx/FITTER-AI) 是一个 Telegram 机器人，可以根据您的膳食照片估算卡路里。
- [Okto](https://github.com/sailxx/Okto) 是 Android 、 Windows 和网络的计划程序，带有任务、日历和焦点计时器。
- [Tobi](https://github.com/sailxx/Tobi) 监控 Claude Code 、 Codex 和 Windows 11 上的光标，并让您一键批准操作。
- [TrayMixer](https://github.com/sailxx/TrayMixer) 从 Windows 11 和 Linux（预览版）上的系统托盘控制每个应用程序的音量。
