## Επιλεγμένα έργα

- [FITTER-AI](https://github.com/sailxx/FITTER-AI) είναι ένα bot Telegram που υπολογίζει τις θερμίδες από μια φωτογραφία του γεύματός σας.
- [Okto](https://github.com/sailxx/Okto) είναι ένας προγραμματιστής για τα Android , Windows και τον ιστό, με εργασίες, ημερολόγιο και χρονόμετρο εστίασης.
- [Tobi](https://github.com/sailxx/Tobi) παρακολουθεί τα Claude Code , Codex και Cursor στο Windows 11 και σας επιτρέπει να εγκρίνετε ενέργειες με ένα κλικ.
- [TrayMixer](https://github.com/sailxx/TrayMixer) ελέγχει την ένταση ήχου ανά εφαρμογή από το δίσκο συστήματος στο Windows 11 και Linux (προεπισκόπηση).

## Σχετικά με μένα

Είμαι ο Vlad, ένας νέος, φιλόδοξος προγραμματιστής που αγαπά την τεχνολογία και τον προγραμματισμό. Πάντα μαθαίνω, ακονίζω τις δεξιότητές μου και εφαρμόζω αυτά που μαθαίνω στην πράξη. Θα με βρείτε στο GitHub τις περισσότερες μέρες, να δουλεύω στα αποθετήρια μου, να στέλνω ενημερώσεις και να πειραματίζομαι με νέες ιδέες.

Χρησιμοποιώ Windows 11 και Fedora Linux με κωδικό VS και Android Studio. Δουλεύω με JavaScript, TypeScript, Kotlin, C#, HTML, CSS, JSON και SVG. Μιλάω Ρωσικά, Αγγλικά και Ιταλικά και μου αρέσει ο σχεδιασμός, τα παιχνίδια και η κατασκευή υπολογιστών UI.
