## 注目のプロジェクト

- [FITTER-AI](https://github.com/sailxx/FITTER-AI) は、食事の写真からカロリーを推定する Telegram ボットです。
- [Okto](https://github.com/sailxx/Okto) は、タスク、カレンダー、フォーカス タイマーを備えた、Android 、Windows 、および Web 用のプランナーです。
- [Tobi](https://github.com/sailxx/Tobi) Claude Code 、 Codex 、および Windows 11 のカーソルを監視し、ワンクリックでアクションを承認できます。
- [TrayMixer](https://github.com/sailxx/TrayMixer) Windows 11 および Linux (プレビュー) のシステム トレイからアプリごとの音量を制御します。
